# Contributing to Mopai / 墨排

Thank you for contributing. / 感谢参与行途开源项目。

1. Open an issue to discuss substantial changes before implementation.
2. Keep pull requests focused; include the relevant before/after Markdown and generated HTML when changing rendering.
3. Verify CLI and offline workbench behavior where applicable; document the exact commands and results. Do not claim tests passed if they were not run.
4. Never submit WeChat credentials, access tokens, private drafts, personal information or employer-owned code.
5. Update both the Chinese [README](README.md) and [English guide](README.en.md) when user-facing behavior changes.
6. Do not change the project's license without maintainer approval.

Please use a feature branch and submit a pull request for review. / 请使用独立分支提交 PR，等待维护者审查。
