# Security Policy / 安全报告

Mopai processes Markdown and HTML intended for publication. Treat untrusted Markdown, HTML, image URLs and credentials as potentially sensitive.

## Reporting

Please **do not disclose exploitable vulnerabilities or credentials in public GitHub issues**. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is not enabled, contact the maintainer privately through an established channel rather than posting exploit details publicly.

## Scope

Reports involving unsafe HTML handling, credential exposure, malicious content injection, file access and publishing workflow security are welcome. Include minimal reproduction steps without real credentials or private content.

## Maintainer response

No specific response-time or support guarantee is implied. Fixes and advisories are published after assessment when appropriate.
